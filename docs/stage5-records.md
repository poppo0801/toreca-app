# Stage 5A / 5B: 購入記録・当選率・対戦記録・店舗の位置・AI料金管理

## 5A: 購入記録（下部ナビ「購入記録」）
- 購入記録は**収支の支出と同じデータ**（`purchases` / `purchase_items`）を別の切り口で見る画面。収支で登録した支出、抽選の「購入済み」、購入記録から手動登録した購入は、どこで登録・編集・削除しても同じ内容が両方に出る（複製しないので二重計上されない）。家族共通で、プロフィール別には分けない。
- 一覧: 購入日、商品名・画像、店舗、BOX/パック/セット/個の数量、金額、購入方法、「抽選当選」の印。期間（月・年・全期間）、商品・店舗で絞り込み。
- 商品別の累計: 直接購入の数量（単位別）、BOX×入数＋パックの**パック換算**（入数が未設定の商品は換算しない）、金額。セット商品は「セット商品」に数量・金額を計上し、構成商品へは数量だけを参考として加え、金額は配らない。
- 金額が未入力の購入は**0円とみなさず**、「金額未入力N件」として別に表示。
- 売却は収支画面の収入記録（売却日・店舗/売却先・商品・数量・金額・名義人・購入原価・手数料・送料・参考利益・年間名義人別集計）で既に対応済みのため、変更なし。

## 5A: 応募実績・当選率（抽選管理の右上のグラフアイコン／設定→記録・分析）
過去の応募・当落の**実績**を集計する（次回の当選確率の予測・応募推奨は Stage 6）。
- 当選率 = 当選 ÷（当選＋落選）。**当落が未確認の応募は分母に入れず**「未確認」として別に数える。中止になった抽選も分母に入れず別に数える。発表延期は結果待ち（未確認）。取り消した応募は数えない。
- 複数商品の抽選: 1回の応募で複数商品が当選しても**応募単位では1件**（二重計上しない）。商品単位（商品ごとの当落）は別に表示。希望商品を選ぶ方式は選んだ商品だけ。
- 集計軸: 家族全体／ユーザー別／系列別／店舗別／商品別（商品単位）／期間（当月・年間・全期間。抽選の応募締切日で判定）。
- 確定が5件未満の率は「参考」と表示し、件数を併記する。

## 5A: 対戦記録（設定→対戦記録）
収支・抽選とは独立（`battle_records`）。対戦日・使用デッキ・対戦相手・相手デッキ・勝敗・対戦形式・先攻後攻・備考・対戦した人。日付順の履歴、勝敗・勝率（引き分けは母数に含めない）、使用デッキ別・相手デッキ別。削除は非表示（操作履歴は残る）。
**未確認**: 既存Excel（Book.xlsx）の Sheet3 は作業フォルダに無く、列構成を確認できなかった。そのため基本項目だけの暫定構造で、Excel固有の列・過去データの移行は**未実施**（推測した内容はインポートしていない）。

## 5B: 店舗の位置・距離・交通費
- 店舗マスター: 都道府県、住所、緯度・経度（内部情報。画面に数値は出さない）、往復交通費（円・手動。未設定は空欄）、店舗メモ。住所不明でも登録できる。緯度と経度は両方あるときだけ有効。
- **自宅の位置**（設定→自宅の位置）: 家族共通。住所は普段は表示せず、「住所を表示して変更」で開いたときだけ取得。住所の文字列は DB の列権限で通常の参照から除外し（`get_home_address()` だけが返す）、変更は RPC（自世帯のみ・検証つき）、操作履歴には項目名だけを残す（住所・座標の値は残さない）。位置が変わると店舗の往復交通費の見直しを促す（自動計算はしない）。位置情報の削除もできる。
- **住所→緯度経度**: 「住所から位置を取得」を押したときだけ、入力した住所の文字列を**国土地理院の住所検索API**（無料・APIキー不要）へ送る。押さない限り外部へ送信しない。取得できない場合は緯度・経度の手入力に切り替えられる。有料APIは使っていない。
- **直線距離**: Haversine式（道路距離ではない）。区分と色: 5km未満=緑 / 5〜15km=青 / 15〜30km=黄 / 30〜60km=オレンジ / 60km以上=赤（上限は設定で変更可）。位置が不明な店舗・自宅未設定では距離を出さない。
- 抽選カード右上に都道府県ラベルと距離。詳細には「直線」「往復交通費」を明記。オンライン抽選（店舗の位置なし）では出さない。

## 5B: 抽選カードの表示項目（設定→抽選カードの表示項目）
都道府県・自宅からの直線距離・往復交通費・応募締切・当選発表日時・受取方法・応募方法・購入数量・ユーザー別応募状況を家族共通で選択。既定は重要項目のみ（交通費・応募方法は非表示）。応募締切が近い警告、結果未登録の警告、赤丸通知、★、ユーザー別の応募状況の操作は設定に関係なく常に表示。

## 5B: AI利用料金の管理（設定→AI読み取りの利用状況・料金）
- 標準モデルは **Claude Haiku 5.5（`claude-haiku-5-5`）**。公式の料金・モデル情報（platform.claude.com/docs、2026-10-29確認）: 入力 $0.10 / 出力 $0.50 per 100万トークン（プロンプト10万トークン以下）、提供中、廃止は2027-10-07以降。画像入力のトークン換算は公式に記載がないため、API応答の実トークン数（画像分を含む）をそのまま使う。精度が足りなければ環境変数 `AI_MODEL=claude-sonnet-5-5`（$2 / $10）に切り替える。
- 表示: 当月の解析回数（文章・画像・URL・X別）、入力/出力トークン、使用モデル、推定料金（円）、月間予算（既定3,000円）と使用率、過去月の利用状況。
- 警告: 予算の1/3・2/3・5/6（3,000円なら 1,000 / 2,000 / 2,500円）で設定画面とAI読み取り画面に警告、予算に達したら「自動AI解析は停止」。**自動AI解析（Stage 4C）は `canRunAutoAnalysis` で予算超過・OFF設定時に止められる構造**。手動の読み取りは止めず警告のみ。
- 料金はあくまで**推定**（トークン数×公式単価×概算為替レート150円/ドル）。実際の請求額は Anthropic Console が正。実際のAPIによる精度・実料金は**未検証**（APIキー未設定）。
