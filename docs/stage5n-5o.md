### 機能
- 会員番号管理（設定 > 会員番号）。ロゴ｜系列名｜番号｜コピー。系列名検索・編集・削除・重複防止。
- 日付クリア（✕）: 全 FlexField・発表終了日・有効期限・応募日時。時刻を勝手に補わない。
- 登録時の応募状態: プロフィールごとのチェックボックス（チェック時のみ結果を選択）。
- 購入期間と受取期間の分離（チェックで受取期間を別入力）。AI は区別が読み取れたときだけ分離。
- 当選後の状態: 購入手続き済み（受取待ち）／受取済み。購入と受取が同じ期間なら「受取を記録」のみ。分離時は「購入を記録」→「受取を記録」。購入記録は応募ごとに1件（二重計上なし）。
- 通知: 購入期限・受取期間開始・受取期限・当日・期限超過。購入済みで購入通知停止、受取済みで受取通知停止。担当プロフィールの当選分のみ。
- 抽選方式: 通常／継続／招待制販売。応募済みタブ最下部に折りたたみ「継続中の抽選 N件」（系列単位・通常件数に含めない）。リセット/失効は手動記録（勝手に解除しない）。
- 締切後の応募記録（詳細）: 現在のプロフィールのみ。実際の応募日時が不明なら `applied_at = null`。
- 応募済みタブ: 発表日基準（太字・発表期間中/結果未確認バッジ）、当選/落選ボタン、発表前は確認ダイアログ。当選タブ: 1行の下段（当選者アイコン・次の期限・現在のプロフィール用ボタン）。

## Stage 5O
- 49: `revert_fulfillment`（直後5分以内・金額未入力・原価未使用の自動作成購入記録だけを戻す SECURITY DEFINER）。
- スワイプ（スマホのみ・マウスでは無効）: 全情報 右＝★追加／左＝今回スルー、★管理対象 右＝応募済み／左＝解除、応募済み 右＝当選／左＝落選、当選 右＝受取済み。
  - 判定は `src/lib/swipe.ts`（10px で軸確定、横が縦の1.8倍以上のみ横、72px/幅25%で確定、確定後 450ms は受け付けない、通信中は無視）。縦スクロールは `touch-action: pan-y` でブラウザに任せる。
  - 操作ごとの有効/無効は `src/lib/swipe-actions.ts` の `SWIPE_OPS_ENABLED`。端末設定（設定 > メニュー・表示設定）でも全体オフにできる。
  - 購入と受取が分かれた当選は選択ダイアログ（Undoなし）。期間前は無効。複数商品の当落は詳細で入力。
- Undo 通知: 画面上部に浮かせ（セーフエリア内・レイアウトを押し下げない）、約3秒、下部の進捗バーが左→右へ。連続操作では最新の操作だけ取り消す。DBも戻し、失敗時はエラー表示。
- シンプルカード: ★を左上端へ（小型化）、店舗名の幅を拡大。
- 「？」ガイドにスワイプ早見表、アイコン凡例を1行に。説明文は `InfoTip`（ⓘ）/`InfoNote`（補足）に統一（自動収集設定・マスター等）。
- マスター: 商品＝画像｜名前｜画像｜編集｜⋯（構成）、系列＝ロゴ表示（未登録はプレースホルダー）＋ロゴ未登録フィルター、仮登録は「仮」バッジ、アーカイブ→「非表示」。表示管理モードで系列・店舗・商品を一括で非表示/再表示（削除ではない・紐付けは維持・新規登録候補から除外）。
