# Stage 7N: 抽選詳細のUI改善・要確認の解除・対戦カードの微調整

## 抽選詳細
- 上部の日付4項目と下部の情報ブロックで左右の余白を統一。2列部分は中央に薄い縦線（左セルの右罫線）。日付は枠なし、下部は外枠＋横罫線のまま。
- 項目名は10pxの薄いグレー。日付のみ中太字。日時は「〜」の位置以外で改行しない。
- 本人確認・書類は長文のとき3行で省略し「詳細を見る」で全文（全文はDOMに保持）。
- 備考は12.5px・行間1.45。箇条書きは維持。
- 登録経路・情報元リンクは常時表示（折りたたみ廃止）。URLは省略表示、タップ領域32px以上。
- 「応募制限」と「適用される応募制限」を1項目に統合（抽選固有の制限は適用される制限に含まれる）。未確認は警告色にせず「未確認」と表示。

## 要確認
- 表示仕様は従来どおり（初期は閉じる・「要確認（N件）」・0件で非表示）。
- 「確認済みにする」を展開ブロックに1つ。表示中の注意をまとめて解除し、`lotteries.cautions[].ackAt` に保存（DB変更なし・マイグレーションなし）。
- 解除済みの注意は、同じコード・同じ内容で再収集されても復活しない（`planCompletion`）。内容が変われば新しい注意として表示。
- 自動解除: 不足系は現在の内容から再評価（従来）。相違系（締切・当選発表・応募方法・受取方法）は、保存で該当項目が変更されたときだけ解消（`pruneCautionsOnEdit`）。編集しただけでは解除しない。
- AIの矛盾判定: 金額・価格・料金だけの食い違い（税込891円とチケットサイトの0円など）は矛盾にしない（`isUnmanagedConflict`。AIプロンプトにも明記）。応募期間・当選発表・受取・条件・店舗・商品に触れる矛盾は維持。保存済みの金額差のtext_conflictも表示しない。

## 対戦記録カード
- アイコン20→17px、アイコンと名前の間隔を縮小、ユーザー名は自分・相手とも通常の太さ（幅3.75rem固定で開始位置を揃える）。
- 勝敗記号を6px左へ（大きさ・色・上下中央は維持）。日付は14→12.5px（太字維持）、形式バッジとの間隔を広げた。
