## 発見した問題と改善
1. **「抽選ではない」判定でも費用が発生するのに、使用量が記録されていなかった** → 使用モデル・トークン数を返して記録（単体テストあり）。
2. 購入数量の上限（お一人様1点まで）を応募回数の制限と誤認 → プロンプトで区別、購入上限は別欄へ。
3. 「系列 店名」を分けられない／オンライン販売の系列 → プロンプト改善＋既存系列からの分離（要確認の印つき）。
4. 画像内のURLの見落とし、原文にない誤字の混入 → プロンプトで「原文のまま写す・URLも読む」。
5. AIの警告に内部用語（year・null）が混ざる → プロンプトで禁止し、残ったものは除去。
6. 商品名に「1BOX（30パック入り）」が混入 → プロンプトで数量・入数を別項目へ（再確認済み: 商品名=「拡張パック「ひかりの森」」、数量1・BOX）。
7. X取得の宛先が転送されていた（publish.twitter.com → publish.x.com） → 直接 publish.x.com を使用。
8. APIエラー（認証失敗・権限・モデル不明・**残高不足**・混雑・入力過大）を利用者向けの案内に変換（本文は返さない。単体テストあり。実際の残高不足・無効キーの状態は再現していない）。

## 料金（実測の使用量から）
- 1回あたり入力約3.4〜4.5千トークン・出力約0.8〜2.7千トークン（URL記事は入力8.2千・出力3.9千）。**推定は1回あたり約0.1〜0.4円**（Haiku 5.5: 入力$0.10 / 出力$0.50 per 100万トークン、150円/ドルの概算）。
- 検証18回の合計は**約3.8円**（使用量が記録できた13回=約2.7円、記録のなかった4回は平均で概算）。同じ量を Sonnet 5.5 で行うと約55円（13回分）で、約20倍。
- 月間予算3,000円に対して、月に数百回読み取っても数十〜数百円の見込み（推定）。実際の請求額は Anthropic Console が正。
