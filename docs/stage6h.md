# Stage 6H: 店舗・地域・商品判定の改善とUI調整

## 1. 自動収集の店舗・地域判定
- **Xアカウントからの店舗特定**（`src/lib/collector/store-identity.ts`）: X APIの `user.fields`（表示名・所在地・自己紹介。同じ応答に含まれ追加課金なし）を取得し、表示名から系列名・店舗名を読み取る（例: 「TSUTAYA 竹原店」→ 系列 TSUTAYA／店舗 竹原店）。マスターの系列・店舗（名称・別表記）と照合し、一致すればそのIDと都道府県を使う。
- **所在地は推測しない**: 都道府県の根拠は「店舗マスター」「公式アカウントのプロフィールの所在地欄（明記）」「告知の本文・画像」「確認済みの対応づけ」だけ。アカウント名・店舗名の地名だけでは確定しない。同名の店舗が複数あるとき、マスターとプロフィールの所在地が食い違うときは確定しない。
- **公式とまとめの区別**: 「抽選・まとめ・情報・ポケカ…」などを含む表示名はまとめアカウントとして扱い、まとめアカウントの投稿は引用元（公式）の投稿者を対象にする。
- **再利用**: 特定できた対応は新テーブル `x_account_identities`（世帯単位・RLS）に保存し、次回以降は表示名が取れなくても再利用する。確認済みの情報を、根拠の弱い情報で上書きしない。
- **公式店舗情報の調査**: TSUTAYA 公式の店舗検索は自動アクセスを受け付けず（メンテナンス表示へ転送）、OpenStreetMap の検索も支店名では正しい店舗に当たらなかったため、これらを根拠にしない。確定できない所在地は「所在地未確認」として保留（自動追跡）にし、店頭抽選を関西として自動登録しない（全国通販は例外）。
- **都道府県が空の店舗の補完**: 登録時に確実な根拠のある都道府県（告知・一覧・店舗の住所）を店舗マスターへ補う（既存の値は変更しない。オンライン専用は対象外）。住所の地図検索（位置情報の取得）が成功したときも、空の都道府県を検索結果から補う。既存分は `scripts/backfill-store-prefecture.mjs`（既定は調査のみ／`--execute` でバックアップ後に実行／`--restore` で復元）。
- **既存候補への適用**: `POST /api/cron/identify`（CRON_SECRET・運用操作）。未確認のXアカウントのプロフィールを最大15件取得（X APIの従量課金）、候補の空の項目だけ補い（元の値は `draft.identify.before`）、その後は既存の再評価（`/api/cron/reevaluate`・AIなし）で登録／追跡／除外を判定。

## 2. ポケモンカード以外の除外（`src/lib/collector/category.ts`）
- 他TCG（ONE PIECE・遊戯王・デュエル・マスターズ・ヴァイス・MTG ほか）の語があり、ポケモンカードの語が無いときだけ除外。AI解析の前（一覧・X投稿の事前判定）と後（`evaluateCandidate`・再評価）の両方で使う。種別が不明なだけでは除外しない。
- 複数TCGを案内する告知は除外せず、ポケモンカードの明細だけを残す。

## 3. 画面
- 自動収集: 「⑤ 収集候補」は展開式（初期は閉じる。見出しに「候補N件・要確認M件」）。「編集して登録」の右に「除外」（この候補のみ・元に戻せる）。要手動確認の一覧は約3件の高さで内部スクロール（見出し・件数は固定、`overscroll-contain`）。
- コレクション: 右上に［相場更新］［＋カード登録］（高さ40px）。「…」メニューからは外した。
- 抽選一覧: タブは2行（上=名称／下=件数。新着バッジは件数の右）。全タブ同じ高さ。
- 未応募のユーザーアイコン・記号を薄いグレーに（不透明度 50%→36%）。応募済み・当選・要確認は従来どおり。
- エフェクト: 静止時は何も被せない（画像本来の色）。触れた位置の周囲にだけ、虹色の筋（soft-light）と細い反射の筋。上位ティアは数秒おきに細い光が1回走る。

## 4. 検証（実測）
- エフェクトの色再現（同一画像・光沢なしとの平均色差。0〜255）: 静止時 旧10〜26 → 新 0／操作時 旧17〜44 → 新 3〜10（AR・SR・SAR）。
- 画面幅 320・375・390・430px（実Supabaseのテスト世帯・架空データ）: 横スクロールなし、タブ高さ同一・件数が名称の下、相場更新はカード登録の左（高さ40px以上）、収集候補は初期に閉じる、要手動確認は216px以下で内部スクロール（画面全体は動かない）・詳細へ移動可能。
- 未確認: iPhone実機（指の動きに応じた光・内部スクロールの触感）。
