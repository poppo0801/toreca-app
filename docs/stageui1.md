# Stage UI-1: UI・操作性改善

ブランチ `ui-1`（`dev` から分岐）。DB変更・マイグレーションなし（プロフィール別設定は既存の `profile_settings`（jsonb）を使用）。情報収集・AI解析・候補判定・自動登録のロジックには触れていない。本番DBへの書き込み・デプロイ・mainへのマージなし。

## 1. NEW表示・既読（`lottery-card.tsx`・`lottery-detail-sheet.tsx`）
- 大きな「NEW」バッジを廃止し、カード右上の角に少し重なる小さな●（`new-dot`。操作を受けない・読み上げ用に NEW の文字）。詳細ヘッダも小さな●。
- 既読は**詳細を閉じた時点**: `onOpenChange(false)`（閉じるボタン・スワイプ・背景・Esc）と、親が `open=false` にした場合（戻る操作）で1回だけ。開いただけ・別画面への遷移でのアンマウントだけでは既読にしない。通信失敗（`ok:false`・例外）では既読にせず再読み込みもしない（NEWが残る）。
- 既存の NEW は抽選行の `is_new`（世帯共通）で、これは変更していない（「ユーザー別」ではなく、既存仕様のまま）。

## 2. シンプル表示の応募ボタン（`apply-status.tsx`）
- 未応募の丸「未」→文字つきの「応募」ボタン（主要操作の色）。既存の共通処理（`MyApplyButton`）を再利用: 店舗選択式・複数商品式は既存の選択フロー、ユーザー別の応募記録、応募済みは✓（解除は既存の確認つき）。クリックは伝播させず、処理中・`busy` 中は二重実行しない。

## 3. グループ化カード（`lottery-group-card.tsx`・`lottery-group.ts`）
- 親: 商品画像（大きめ）・系列（小さめ）・商品の**正式名称**・**グループ内で共通している**応募期間・発表日・締切までの残り時間・現在のユーザーの応募状況（応募済み N/M店舗）。日程が異なるときは「店舗により異なる」と示し、特定店舗の日程を代表にしない（締切の残り時間は「最短」と明示）。商品の組が異なるときは画像・名称を代表させない。
- 応募状況の分母: 各抽選が別々の店舗なら「店舗」、店舗選択式・同じ店舗の抽選を含むなど店舗数と一致しないときは「件」。
- 子（全情報・要チェックのタブ）: 店舗名・地域（都道府県＋住所から市区町村）・応募ボタン。**親と共通する商品・日程・条件は繰り返さず、異なる項目だけ**を表示。タップで従来の抽選詳細。応募済み・当選タブは従来の子カード。グループ化の判定ロジックは変更なし。

## 4. 下部ナビゲーション（`profile-settings.ts`・`nav-menu.tsx`・`nav-settings.tsx`・`app-shell.tsx`・`quick-menu.ts`）
- 構成: **A=固定5項目**／**B=固定4項目＋右端「メニュー」**（既定B＝従来の4項目＋その他の操作感）。プロフィール別に保存（`nav`・`navMode`・`quickNav`。設定コピーの対象にも追加）。
- 機能の登録: `NAV_ITEMS`（`profile-settings.ts`）に1行＋アイコン（`page-heading.tsx` の `NAV_ICON`）に1行で、メニュー・固定項目・ショートカットの選択肢に現れる（**151図鑑・相場調査メモなどの将来の機能もここに追加**）。`available:false` は出さない。
- 権限: `adminOnly`（抽選候補・自動収集）は管理者のプロフィールだけ表示・選択可。`supabaseOnly` は保存先のあるモードだけ。保存値は必ず補正（存在しない・重複・権限外・不足・過多）。UI非表示だけでなく、既存のサーバー側の権限制御（候補ページ・収集API・各アクションの管理者判定）は変更していない。
- メニュー（通常タップ／クリック）: 全機能のアイコン＋名称グリッド（`nav-grid`）。Aではメニューが無いため、設定画面の「すべての機能」から全機能へ。
- 長押しクイックメニュー: 長押し420ms → 画面右下から上方向に最大6項目 → 上へドラッグで指の位置の項目をハイライト → 離すと移動／範囲外で離す・pointercancel・Esc・画面非表示・リサイズはキャンセル。`touch-action:none`＋ポインターキャプチャでスクロールを止め、`select-none`・`-webkit-touch-callout:none`・contextmenu抑止。通常タップ／キーボード（Enter・Space）は全機能メニュー。長押し直後のclickは抑止。
- 設定（メニュー・表示設定）: A/B切替・固定項目の並び替え（ドラッグハンドル・上下）と各行の機能の入れ替え・長押しショートカットの追加/外す/並び替え・初期の構成に戻す。権限変更で補正したときは注記。
- PC: 固定項目＋メニューボタン（クリック）。左サイドメニューは従来どおり無し。
