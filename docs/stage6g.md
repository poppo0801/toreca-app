# Stage 6G: 自動収集データの整理・関西重点運用・コレクション相場一括更新

## 1. 自動収集（関西3府県）
- **収集条件を本番に反映**: 対象地域を兵庫県・大阪府・京都府のみ、通販（全国から応募・発送可能）は収集する設定。本番の `collection_settings` に保存し、読み戻しで確認済み（次回の定期収集から有効）。画面の地域絞り込み（端末保存）とは独立。
- 判定（`src/lib/collector/conditions.ts`）: 複数地域の表記（「大阪府・東京都」など）に関西が含まれれば対象。店舗名に地域名が1つだけ明示されている場合のみ都道府県として読む（「千葉中央店」→千葉県）。読めない地域は関東と推測せず、確認（自動追跡）に回す。
- 再評価（既存の Stage 4C 再評価＋6D の統合／低情報量パス）を本番で実行。バックアップ（`backups/2026-11-05T08-49-13-125Z/`）取得後、まず3件で検証し、残りを実行。AI解析は使わない（クラスCのみ3件・約1.15円）。
- 結果（確認待ち 61件）: 応募期限終了 2件・地域対象外 4件を除外 → 確認待ち 54件。うち自動追跡 42件・要手動確認 10件・その他 2件。新規の自動登録はなし（残りは系列・店舗・商品の確定、または受取方法が必要で、推測しない）。候補は物理削除なし（460件のまま）。応募・当落履歴（24件）は変更なし。
- 除外済み候補の内訳（本番・累計）: 応募期限終了 60／地域対象外 173／自動除外 105（＋手動除外 4）。

## 2. アーカイブ（`src/lib/collector/archive.ts`）
- 通常の一覧・件数から隠す: 重複・応募期限終了・地域対象外は即時、自動除外・手動除外は3日後。削除はしない。理由は除外時の理由文言から判定（追加の列なし）。
- 管理画面「⑥ 整理・一括再評価」でアーカイブの件数を確認し、「地域対象外・自動除外を確認待ちへ戻す」→再評価で、設定変更後に再評価できる。
- 重複収集の防止は、既存の識別キー（X投稿ID・元URL＋締切日付）の一意制約で行う（除外・アーカイブ済みの行は残るため、再掲載でも新規の確認待ちを作らない。締切日が違う次回の抽選は別の候補）。

## 3. 一括再評価（管理画面）
- 「対象を確認」（DB変更なし。予定の件数を表示）→「実行」。20件ずつ処理して進捗バーを表示。結果の内訳と詳細（折りたたみ）。途中で止まっても冪等で、もう一度確認から実行すれば残りから再開。二重実行は画面で無効化＋サーバー側で拒否。AI・X APIは使わない。

## 4. コレクション相場（ポケカ価格比較）
- **調査結果**: https://card.pricebest.jp/data/prices.csv は誰でも取得でき（HTTP 200・約490KB）、robots.txt は全許可。サイトは「オープンデータ」として公開し、出典・取得日時つきと説明。ただし**再利用・保存・外部アプリでの利用を明示した利用規約／ライセンスは確認できなかった**（免責事項・サイトについて・掲載基準を確認）。取得元は各店舗の公開価格で、1日1回の更新。
- **方針**: 許可が明示されていないため、定期の自動取得はしない。利用者が「相場を一括更新」を押したときだけ1回取得（自分用・5分以上あける・識別できるUser-Agent）。取得したくない場合は、同じ画面の「CSVから取り込み」で手動取り込み。運営者への利用確認は未実施（連絡先は掲載店舗向けの窓口のみ）。
- **CSV形式**: 1行目 `# updated: …`、2行目に見出し13列（shop_key, shop, type, kind, set, no, name, rarity, condition, price_jpy, in_stock, source_url, scraped_at）。2026-11-05 取得分は 2,788 行（シングル販売1,676・シングル買取353・BOXほか）。対象は13弾の高レアのみ。
- **照合**: 収録弾＋カード番号が一致する行だけを候補にし、レアリティ→名称で絞る。1つに絞れなければ「照合未確定」（価格を確定しない）。画面で候補から選ぶと保存（`card_market_links`）し、次回以降も再利用。弾・番号が未登録のカードは「情報不足」。
- **集計**: 販売と買取を別々に集計。販売は在庫あり・状態が「標準／A／A-」の行のみ（売切・B/C・中古・BOXは混ぜない）。同じ店舗は1件（販売=最安／買取=最高）。参考価格は中央値、最安販売・最高買取も表示。3店舗以上で中央値の5倍超／1/5未満は外れ値として集計から外す。1件のときは「参考データ1件」。**カード状態（A+〜C）による補正はしない。**
- **保存**: `card_market_prices`（カード×販売/買取で現在値1行・店舗別内訳つき）。手動の参考相場（`card_prices`）・取得価格は一切変更しない。取得・形式検証に失敗したときは既存の価格を変更しない。
- **画面**: コレクションの「…」メニュー →「相場を一括更新」（対象数・最終更新・更新／未掲載／照合未確定／情報不足の件数）。カード詳細に販売相場・買取相場・最終取得・参照サイト（リンク）・件数を表示。「実際の取引価格や査定額を保証しない」旨を案内。
- **実データでの確認**（2026-11-05 のCSV・コレクション2枚）: ブラッキーex SAR（SV8a 217/187）= 販売中央値56,000円（最安49,800円・3店舗）／買取44,000円（1件）、エーフィex SAR（SV8a 211/187）= 販売7,980円（最安6,900円・3店舗）／買取5,000円（1件）。2枚とも照合成功。
- DB: 追加のみ（`card_market_prices`・`card_market_links`、RLS）。マイグレーション `20261116000060_stage6g.sql` を本番に適用済み。バックアップ対象に追加。
