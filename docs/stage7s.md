# Stage 7S: マスター管理UI・店舗削除/アーカイブ・オンライン店舗統一・所在地整備

## UI
- マスター管理の種類ボタン: 1行目は プロフィール／系列／店舗／商品／その他▼。その他の種類は初期状態で畳み、選択中はボタンに現在の種類名を出す。
- 検索欄のフォーカス時、`visualViewport` の見えている領域で判定して `#app-scroll`（アプリ内のスクロール領域）だけを動かす（`src/lib/use-scroll-input-into-view.ts`）。画面全体の transform・window のスクロールは使わない。閉じたときは何もしない（押し上げの復元は 7P の `use-keyboard-inset`）。**実機（iPhone Safari/ホーム画面版）での確認は未実施**。

## 削除・アーカイブ
- 店舗: 編集ダイアログの「削除」→ 参照件数を表示。参照なし=完全削除（`delete_store`）、参照あり=アーカイブ（非表示。表示管理で復元）。系列は既存の削除ダイアログ（参照なし=削除／あり=非表示）。
- 店舗の統合 `merge_store_masters`（同じ系列内。参照を付け替え、統合元の名称を別名に残して削除）。

## オンライン店舗
- 内部: `sales_kind = 'online_only'`、標準名「通販」。表記ゆれ（オンライン/通販/通販店/ネットショップ/eストア…）は `store-online.ts` で同一視（照合・登録・自動収集・重複判定 `storeKey` / `matchStore` / `isOnlineLikeName`）。
- 表示: 実店舗と混在する系列は「系列名 通販」、通販だけの系列は「系列名」。
- 保存時、オンライン系の店舗名は既存のオンライン店舗に寄せ、無ければ「通販」で作成して `online_only` にする。

## カードボックス
- 「所属未確認」系列を直営へ統合（応募アカウント・応募・収集設定を移行）し、旧系列はアーカイブ。未確定の店舗名は `item=null` の候補確認（直営/その他）。

## 所在地
- `scripts/apply-store-locations.mjs`: 調査した住所を国土地理院の住所検索で検証し、番地が一意に一致したものだけ反映。既存の住所は上書きしない。
- 「所在地を取得」は既存の住所→座標の取得（国土地理院・無料）を利用。名称からの検索は、規約・費用の確認が必要なため未実装。
