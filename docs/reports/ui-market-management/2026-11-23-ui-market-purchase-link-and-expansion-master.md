| 詳細の操作ボタン | 右=編集・更新・完売／左=この価格で購入・削除。「カード情報を編集」の独立ボタンは廃止し「編集」に統合（151図鑑: 価格とカード情報を同じフォームで編集、変更時のみ同カードの全価格記録へ反映。相場調査メモ: 価格編集にカード情報も含む） |
| 番号・レアの入力 | 番号の候補は番号単独（これまで入力した番号＋マスターのエキスパンションマーク、先頭1文字で絞り込み・自由入力可）。レアは独立（番号を選んでも変わらない）。番号→収録セットの補完: 一意なら自動入力、複数候補は選択、入力済みと矛盾するときは上書きせず注意表示、不明は自由入力。自動入力した値は番号を直すと追従。画面の呼称は「番号」。未入力でも登録可 |
| 収録パックマスター | `expansion_marks` 表（マーク・正式商品名・収録セット名・シリーズ・種別・出典・最終確認日・有効状態）。SV1〜現行（M シリーズ含む）の拡張パック・強化拡張パック・ハイクラスパック **35件を有効**、デッキ・BOX等51件は無効（候補に出さない）で保持。SV1S=スカーレットex、SV1V=バイオレットex、SV1a=トリプレットビート、SV2a=ポケモンカード151、SV8=超電ブレイカー を確認。`series` 列で SV 以前への拡張可 |

| 相場比較表の統一 | 日別結果の比較表を基準に、系列・店舗の表示を共通部品（`StoreIdentity`）化し、比較表と各カードの価格一覧で使用。日付のみ表示（「調査」削除）、系列名を店舗名より太く、系列名の左に小ロゴ（未登録は頭文字の小タイルで代替）。カードの同一性は従来どおり（セット・番号・レア違いは別の表。情報不足では統合しない） |
| 一覧の整列 | レアリティ・状態ランク・価格を固定幅の列にし全行で位置を統一。店舗名・カード名は小さくし、店舗名は最大2行で全文を表示。横スクロールなし |
| 不具合修正 | 番号の絞り込み用の正規化関数で `\s` が `s` になっていた不具合（"SV8" の "S" が無視される）を修正 |

## 2. 情報源の検証（収録パックマスター）
- 取得元: ポケモンカード公式サイト カード検索（`https://www.pokemon-card.com/card-search/`）。商品名一覧と、商品ごとのカード検索結果（1ページ目）に含まれるカード画像パス（`card_images/large/<エキスパンションマーク>/`）からマークを取得。**商品名・マークのみ保存**（画像・本文は保存しない）。
