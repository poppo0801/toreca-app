## 1. 変更点
| 項目 | 内容 |
|---|---|
| 相場調査メモの一覧 | 収録パック名を廃止し、番号（例: SV8）だけを小さな枠で表示。レアリティの左右の縦線を削除し、文字を小さく（11px）。列は固定幅（レア・状態ランク・価格）で、カード名・店舗名の長さに関係なく位置が揃う |
| 相場比較表の共通化 | 新しい共通部品 `compare-row.tsx`（`CompareRowContent` / `COMPARE_ROW_CLASS`）を、①本日の調査結果の比較表 ②相場調査メモのカード詳細 ③151図鑑の詳細 の3か所で使用。1行目=［小ロゴ］系列名（太字）店舗名 ｜ 状態ランク・価格、2行目=日付（小さく・「調査」なし）。行の高さ・余白・角丸・文字サイズ・区切り線は共通。各行に収録パック名・番号・レアは出さない。最新／過去の参考情報の区別・完売表示・購入済み・最安・参考価格などの既存表示は維持 |
| 系列・店舗の表示 | `StoreIdentity` を1行表示に変更（ロゴ・系列名・店舗名が同じ行。長い店舗名は末尾を省略） |
| 151図鑑のカード種類別分離 | 価格一覧を、カードの同一性キー（収録セット＋番号＋レアリティ。セットか番号が空のときは名前も含めて判定＝未入力のカードを誤って統合しない）ごとの比較表に分割。種類が2つ以上のとき見出し「番号・レアリティ」（例: SV8・AR／SV8・SAR／SV2a・SAR）を表示。種類が1つなら見出しなし。価格・購入・履歴データは不変（表示の分割のみ） |
| 並び替えボタンの長押し（iOS） | 押下中・長押しで一覧を開いた直後だけ `selectstart` を止め、開いた時点で既存の選択を解除。ボタンと一覧に `user-select:none` / `-webkit-user-select:none` / `-webkit-touch-callout:none`。通常タップの循環・長押し直後の click を無視する動作は維持。保護は約0.6秒で解除し、画面全体の選択・スクロールは制限しない |
