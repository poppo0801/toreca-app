## 2. AI読み取りのURL統合（V09）
変更（PR「AI読み取りのURL入力統合（V09）・説明文の整理（V10/V11）」、`main` b40a5b8）:
- **入力は「文書／画像／URL」の3種**（旧: 文章・画像・店舗URL・X投稿の4種）。URL入力欄は1つ。URL形式エラーは取得前に理由を表示。
- **取得方式の自動判別**（`src/lib/url-input.ts`＝URLの形式判定だけ。公式かどうかは判断しない）: X投稿URLは既存のX取得（oEmbed＋リンク先・添付画像）、その他は既存の一般Web取得（robots・安全な取得部品）。**公式サイト以外のURLも受け付ける**。
- **リダイレクト対応**（`lottery-extract-service.ts`）: 短縮URL（t.co・bit.ly 等）は転送先を最大3回まで確認（本文は取得しない・既存の安全な取得部品）して取得方式を選ぶ。一般のURLの転送先がXの投稿だった場合もX用の取得で読み直す。
- **情報源の信頼性評価は別**: 取得方式の判別と、公式性・信頼性の評価（検証層・照合）を分離したまま。非公式URLを公式とはみなさない。
- **取得失敗の案内**: 失敗の原因（ロボット拒否・短縮URLの転送先不明・JavaScript表示・Xの取得不可など）と、次の手段（文書の貼り付け・画像）を表示。取得できなかった内容を推測しない。
- 既存の読み取り・抽選登録は不変（API の `kind=url/x_url` は互換のため残置）。DB・費用上限・環境変数は未変更。
