### 1.2 上限の監査で見つけた「無言の欠落」と、横断調査（指示書 §2）

「設定値を増やした」ことは網羅性の証明ではないため、取得した情報が各段階で失われないか／失われたら記録されるかを測る仕組み（§2）を作り、**その過程で次の無言の欠落を発見し、修正した**。

| # | 欠落 | 段階 | 修正 |
|---|---|---|---|
| a | https以外（http）のリンク先ページ、短すぎるページが、取得できたのに**無言で保存対象から外れ**、台帳は「取得済み」のままだった | 保存 | 保存されなかったページは台帳を「保存されなかった（not_stored）」へ更新し、件数を `limitHits`（pagesDroppedNotHttps / pagesDroppedTooShort / pagesDroppedOverCap）に記録 |
| b | 解析へ渡す統合テキスト（20,000字）の末尾が**無言で切られていた**（投稿が長いと、後ろのリンク先本文・未取得リンクの一覧が消える） | AI入力 | 切るときは本文に「解析の入力の上限のため省略。全文は保存済み」と明記し、`inputTruncated`・切る前の字数を返す |
| c | 長文の目次が最大96,000字（1,200字×80）までで、**120,000字のページの末尾に目次が無かった** | AIの参照 | 目次の粒度を全文に合わせて広げ（最大80項目で末尾まで届く）、監査（outlineReachesEnd）で検査 |
| d | リンク（60件）・台帳（80件）・画像参照（16件）・linkMap（30件）・画像読み取り（12件）の上限で落ちた件数が**記録されていなかった** | 保存 | `limitHits`（linksDropped / ledgerDropped / imageRefsDropped / linkMapDropped / imageReadingsDropped / textTruncated / pagesTruncated）に件数を記録 |
| e | 画像と本文の日付照合に使う本文が60,000字で切れ、後ろの日付を見落とすと画像の日付が「画像のみ」と誤判定されうる | 照合 | 上限を1,000,000字へ（30ページ×最大120,000字が収まる） |
| f | 旧方式（統合判断）の入力が証拠8件で切れ、複数リンクのページが**無言で落ちていた** | AI入力（旧） | 上限を `MAX_LINKED_PAGES + 4` に |

**同種の問題が残っていないかの横断調査**: `src` の `slice(0, N)`・上限定数を全て洗い出し、`LIMITS`（実際の定数から集めた表。`limits-audit.ts`）に載せた。各上限に「当たったときの扱い」（台帳／記録／AIの入力に明記／再取得キュー／粒度の適応）を持たせ、**無言のものは0**にした（テストで検査）。残る切り詰め（`omitted.slice(0,20)` の未取得リンクの一覧表示は件数も併記・`readings.slice(0,12)` はAI入力の注記で件数を示す・`linkedPageText.slice(0,6000)` は互換用で全件は `linkedPages`）は、記録または全文が別にあるものだけ。

### 5.2 実データの制約と、R1の組み立て

- 保存済みの実投稿30件のうち、リンクを2件以上持つのは1件・短縮URLは未展開で、リンク先の本文を取得済みの複数リンク案件は**実データに存在しない**（外部制約）。
- そこで **保存済みの実在の公開ページ（LivePocket 12件）** を使い、ページ単位で人が確認したgold（店舗・商品・締切・応募単位・根拠の引用）から、複数リンクの比較用の案件12件を**決定的に**組み立てる（投稿の文面は保存済みの実投稿と同じ書式で合成。ページの本文は実在）。同じページを複数の案件で使い回すため、案件は独立ではない（検出力は割り引いて読む）。**これは実投稿の複数リンクではない**ことを結果の報告に明記する。
- 人が確認しやすい資料を作成済み（ローカル・Git管理外）: `eval/phase2-compare/r1-worksheet.local.md`（ページごとに、原文の該当箇所・機械抽出の候補[未確認]・要確認点）と `r1-gold-pages.template.local.json`（記入用の雛形。12ページ中、店舗の候補6件・「応募締切」の明記から締切と根拠の引用の候補4件を事前入力。**`verified`（人の確認）は空**で、人が確認・訂正して記入するまで正解として使えない）。**AIの出力・旧方式の結果・保存済みの登録案から正解を作っていない**。
