# UI仕様逸脱の全面是正（相場調査メモ一覧・価格記録一覧・購入記録の商品別累計）

作成日: 2026-11-22 ／ 優先順位: 今回のユーザー指示（最優先の確定仕様）＞ 過去の指示書・設計md。今回と矛盾しない過去の確定仕様は維持。

## 原因（過去の誤解釈・過剰な簡略化）
- 「総額」「開封」という**ラベルの削除**を、金額・開封数量という**数値の削除**に拡大解釈した（購入記録）。
- 「省スペース化」を、情報の配置の最適化ではなく**情報・操作の削除や縮小**として実装した（相場調査メモ: 店名を約96pxで省略、最安価格を小さく、3行に縦積み）。
- カード一覧と価格記録一覧の設計を混同した（相場メモのカード一覧に、価格記録の「コンパクト行」の発想を持ち込んだ）。
- 並び替え・購入済み切替の操作が、一覧の最上部で条件付き（購入済みが1件以上のときだけ）の小さなチェックだけになっていた。
