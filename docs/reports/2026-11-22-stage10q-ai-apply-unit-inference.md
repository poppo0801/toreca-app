## 2. 実装

| 部品 | 内容 |
| --- | --- |
| 参考知識ストア（`knowledge/apply-unit-knowledge.json`・`knowledge.ts`） | ユーザー提供の経験則を、出典・適用対象（プラットフォーム/系列/抽選方式）・例外・観測日時・信頼度・反例・有効期限を持つ**データ**として保存。**傾向（tendency）と特定イベントの実例（event_example）を分離**（LivePocketの傾向に、イトーヨーカドーのグループ制が反例として紐づく）。系列の表記揺れは既存の `chainsMatch` で吸収。コードに系列名・プラットフォーム名の絶対判定は無い（静的検査で固定）。人の訂正（`addCorrection`）は人の名義と理由が必須でAI名義は拒否。無効化・反例・例外の追記を反映。**AIの未確認の判断を事例にするAPIは存在しない**（自己強化しない）。期限切れは渡さない。 |
| 推論の入出力（`apply-unit.ts`・`ai-unit.ts`） | 入力: 告知の抜粋・系列/店舗/商品・応募先のホスト・フォームの観察・制限/グループの文言（機械的に抜粋）・過去の実例（同じ系列の既存登録の応募方式の分布。人が確定したものと分けて表示）・参考知識・「店舗マスターは不完全」。出力: 応募の独立単位／選択可能店舗・グループ／商品別フォームの可否／**選択のタイミング（応募時／当選後／不明）**／推論された方式／代替仮説／根拠（直接・類推・未確認＋参考知識ID）／確信度／不明点／追加調査の候補。 |
| 機械検証 | 直接の根拠は、①抜粋が文脈に実在 ②**主張した単位・タイミングを示す語の手掛かり**がある、の両方で認め、満たさなければ類推へ降格。未知の参考知識IDは除去。直接の根拠が無ければ確信度は high にしない。根拠のないタイミングの主張は unknown。**確信度の自己申告・数値だけでは登録しない**。 |
| 判断（`decision.ts`） | 応募単位の状態: 明示／推論（直接の根拠あり）／**暫定（仮説）**／不明。仮説のみなら**自動登録にせず「暫定候補」（`tentative_candidate`）**として、未確定の応募方式・代替仮説・タイミング・不明点・追加調査の候補つきで保持。他の条件が止めるときは確認待ちに**複合の理由**（`unit_provisional_*` と他の理由）を残す。店舗選択式・全店共通・店舗グループ別では、店舗が1つに決まらなくてよい。`candidate_with_gaps`（応募先など実行に関わる項目の欠落）とは別の状態。 |
| 受取タイミング | 当選後に受取先を選ぶ型は、管理上は `store_select`（`appManagedUnit`）、ただし `displayStoreSelectAtApply=false`（応募時に選択必須と誤表示しない）。応募時の選択のときだけ true。 |
| 確認画面 | `scripts/review-10q-local.mjs`（例外・不確実なものを先に。仮説・代替・不明点・追加調査の候補・参照した知識を表示。AI名義は拒否・何も実行しない）。 |
| 補助調査 | 追加調査の候補はAIが `furtherInvestigation` として出力する。公開ページの取得は既存の `investigateStructure`（SSRF・robots・深さ/回数/時間の上限・フォーム送信なし）が使える設計。**今回の実データでは、一覧項目に応募先リンクが無く、実行していない**（取得 0回）。 |

## 8. 次段階（本番シャドー）への提案

**本番シャドーへ進めるのは時期尚早。** 根拠:
1. 実データで**直接の根拠による応募単位の確定が 0** で、仮説は確信度 low のみ。一覧項目に応募先リンク・フォームの構造が無いことが原因。新規収集分の `linkMap`（応募先の展開）と、応募ページの上限つき調査（既存の `investigateStructure`）を接続して、直接の根拠を得る経路を実測する必要がある。
2. 仮説が store_select に偏る懸念（§3.3）を、人の確認で確かめる。確認の結果は `addCorrection`（人の名義・理由つき）で参考知識に反映する。
3. 応募単位が解けても、TCG・地域・重複の条件で自動登録に進めない（§3.2）。
4. 進める場合の段階案（いずれも別承認）: ①マイグレーション 108〜113 の適用計画の再計算とバックアップ ②暫定候補・確認待ちの**表示のみ**のシャドー（登録・通知なし）③人の確認が一定数たまってから、直接の根拠がある推論に限り自動登録プレビューを評価。通知・応募済み管理には、暫定候補の応募方式を断定して出さない。
