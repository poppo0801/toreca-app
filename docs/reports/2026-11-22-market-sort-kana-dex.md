# 相場調査メモ一覧: 五十音順・図鑑No順・現在の並び順の表示・カード行の表示順

作成日: 2026-11-22 ／ UI専用（DB・価格/購入データ・AI情報収集・非公開画像配信は変更なし）

## 変更点と照合
| 要望 | 実装 | 検証 |
| --- | --- | --- |
| 1 五十音順・図鑑No順を追加（既存の価格順・状態優先・新着順は維持） | 並び替えボタンの循環を 新着順→価格の安い順→状態優先→**五十音順→図鑑No順** に。`sortMarketCards` に `dexOf` を追加 | 単体（並び・安定性・入力順を変えても同じ）／E2E（実画面の表示順） |
| 1 五十音順=ポケモンの読み仮名（ex等に影響されない） | カード名→ポケモンを特定し、**ポケモンの読み仮名**（正式名称のカタカナ。♀♂は除く）で並べる。「ex」「V」はカード名側で除去済み | 「ミュウex」「ミュウツー」「ピカチュウV」等で確認。ミュウ < ミュウツー |
| 1 図鑑No順=全国図鑑番号の昇順。番号なし・ポケモン以外は末尾。同一ポケモンは安定した順序 | 番号で昇順。特定できないカードは末尾（新着順）。同一ポケモンは カード名→セット→カード番号（数値順）→ID | 単体・E2E（6,25,350,593,741,なし の順） |
| 2 全国図鑑番号のマスター（番号・正式名称・読み仮名） | 既存の全ポケモン名称マスター（No.1〜1025）を利用。`pokemonMaster(no)` で 番号・正式名称・読み仮名 を返す（公式名称はカタカナのため、読み仮名は名称から生成。別管理の表は不要と判断） | 単体 |
| 2 誤判定しない・判定できないカードは番号なし・既存データは変更しない | 前回の厳密な照合（種別表記を除いた完全一致／許可した接頭／「〇〇の」）を使用。「ミュウツーとミュウ」「ハイパーボール」等は番号なし。DBへの書き込みなし（表示時に計算するだけ） | 単体（ミュウ/ミュウツー、リザード/リザードン、ゴース/ゴースト、複数ポケモンは null） |
| 3 見出しの右に現在の並び順（例: 価格の安い順 ↑） | `MarketMemoPage` で見出し行の右に小さく表示。並び替えで即時更新。↑=昇順/安い順/良い順、↓=新着順 | E2E（各モードで文言を確認） |
| 3 検索欄の幅を狭めない | 並び順の表示は**見出し行**に置き、検索欄の行には何も足していない | 実画面 |
| 4 「・」の削除／表示順 カード名→レアリティ→（セット）→カード番号 | 区切りの「・」を削除。順序は カード名・レアリティ・セット・カード番号 | 単体（DOM順）・実画面 |
| 4 レアリティは太字／カード番号は細い線の角丸四角・細い文字 | レアリティ=`<b>`（font-bold）。カード番号=`rounded-md border`＋`font-light` | 単体（クラス）・実画面 |
| 4 図鑑番号とカード番号は別 | 図鑑番号は画像と並び替えにだけ使用（`data-dex`）。カード番号は枠内に表示 | 単体（ピカチュウ=25 / 132/165 を別に検証） |
| 4 「N件」の削除 | 件数の表示を削除 | 単体・E2E |
| 4 状態バッジ・画像・店舗名・最安価格・右端/縦中央・行全体タップを維持 | 変更なし | 単体・E2E・実画面 |
| 5 既存のコンパクトな2行構成 | 1行目=カード名＋レアリティ＋セット＋カード番号（**1行に収める**。長いセット名は「…」で省略し、全文は title に保持）、2行目=状態バッジ＋店舗（長い店名は折り返し・省略しない） | 実画面（390px） |

- 本番のログイン後画面の目視は未確認。
