# 商品マスターの一括取り込み（Stage 4A）

Excel（商品マスターテンプレート）と商品画像から、商品マスターを登録・補完します。**何度実行しても重複しません**（冪等）。

## 置き場所（コミット・公開されません）
```text
data/import/products/
├─ toreca_product_master_template_v4.xlsx   （*.xlsx。複数あれば最後のもの）
├─ M6_b.png / M6_p.png / 30TH-01_s.png …    （直下、または images/ の中。大文字小文字は区別しません）
└─ _import-report.txt                        （実行のたびに出力されるレポート）
```
`data/import/` は .gitignore 済みで、Vercel の公開領域（public/）にも置きません。

## 使い方
```bash
npm run import:products                 # ドライラン（DBに書き込まない）。件数・差分・画像不足を報告
npm run import:products -- --apply      # 実際に登録。事前に npm run backup を取ること
```
オプション: `--overwrite-fields M6,M7`（既存値と違うExcelの値で更新するコード。手動編集済み項目は対象外）／`--overwrite-images`（取り込み由来の画像のうち内容が違うものを差し替え。手動アップロードは常に保護）／`--dir`／`--household`。

## 取り込みルール
- 商品コードは1項目。コード種別（公式/独自）を `product_code_kind` に保持。コードは大文字小文字を区別せず重複不可（DB制約 + 取り込みの照合）。内部IDは別。
- **空欄は未設定**（推測しない）。「基本販売単位」などテンプレートにない列は取り込まない。入数が空の単品・セットは入数=未設定（30と補わない）。
- 販売形態 `sales_form`: パック/BOX/入数の記入があれば pack_box、単品・セット定価のみなら single_set、どちらも無ければ未判定。
- **新しいコード → 新規**。**既存コード → 未設定の項目だけ補完**。既存値と違うExcelの値は「差異」として報告のみ（更新しない）。手動編集した項目（`manual_override_fields`）は上書きしない。Excelの空欄で既存を消さない。
- 名称だけが一致して別コード（またはコード未設定）の既存商品がある場合は**自動統合せず「要確認」**。
- 略称は追加のみ。他の商品が使っている略称は追加せず報告。

## 画像
- `コード_b.png`=BOX、`コード_p.png`=パック、`コード_s.png`=単品・セット。PNG（透過推奨・3MBまで）。ファイル名の規則に合わないもの・対応する商品がないものは取り込まず警告。
- **画像が無いのはエラーではありません**（片方だけ・両方なしでも登録可）。不足は「画像不足」として一覧表示し、後日ファイルを追加して再実行すれば**不足分だけ補完**されます。画像が無い商品はアプリで共通のプレースホルダーを表示します。
- 既存の画像がある場合は上書きしません。手動で差し替えた画像（アプリの 設定 > マスター管理 > 商品 > 「画像」）は再取り込みでも保護されます。
- 保存先は Supabase Storage の**非公開**バケット `product-images`（パス: `<世帯ID>/<商品ID>/<種類>.png`）。アクセスは世帯単位のRLSで、表示はサーバーが発行する期限付きURL。service_role キーはブラウザに渡しません。
- 表示は元の縦横比のまま（`object-contain`・高さだけ指定）。正方形への変形や余白の追加はしません。

## セット商品
単品（例: 30TH-01〜09）とセット（30TH-SET）は独立した商品です。構成関係は `product_set_items`（構造のみ。**自動推測しません**）。セットの購入は**セット商品の1明細**として記録され、構成商品の数量・金額には加算されません（二重計上なし）。定価の仮計算は「セット」単位でセット商品の単品・セット定価を使います。

## 復元
`product_images` / `product_set_items` は `npm run backup` の対象です。**画像ファイル本体（Storage）はバックアップ対象外**です。元ファイル（data/import/）を保管し、失った場合は再取り込みで復元できます（手動アップロードした画像は元ファイルを手元に残してください）。
