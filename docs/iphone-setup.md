# iPhone で通知を受け取る手順書

夫婦それぞれのiPhoneで同じ手順を行います。所要時間は約5分です。

## 必要なもの
- iPhone（**iOS 16.4 以降**）。設定 → 一般 → 情報 で確認
- **Safari**（他のブラウザからは「ホーム画面に追加」して通知を使えません）
- アプリのURL（例 `https://toreca-app-xxxx.vercel.app`）と共通ログインのメール・パスワード

## 手順
1. **Safari でアプリのURLを開く**。
2. 画面下の **共有ボタン（四角から矢印が出たマーク）** をタップ → 一覧を下へスクロール → **「ホーム画面に追加」** → 名前は「トレカ抽選」のままで **「追加」**。
3. **ホーム画面に追加されたアイコンをタップして開く**（Safariのタブではなく、アイコンから開くことが重要です。上部のURLバーが無い全画面表示になります）。
4. **共通ログイン**でログインする。
5. 画面右上の丸い **A / B / C** から、**このiPhoneで使うプロフィール**を選ぶ（夫の端末ならA、妻の端末ならB など）。
6. 下部メニュー **「設定」** を開き、**「通知」** のセクションで
   「**（プロフィール名）としてこの端末の通知を有効にする**」をタップ。
7. iPhone の許可ダイアログで **「許可」**。
8. 状態が **「有効（通知先: プロフィールA）」** のようになれば完了。**「テスト通知を送る」** をタップして、iPhone に通知が届くことを確認する。
9. 同じセクションの **通知ルール** で、朝の通知時刻（既定 9:00）、締切の何分前に通知するか、日付のみの期限の扱いを好みに合わせて **「通知ルールを保存」**。

## このアプリの通知の考え方（知っておくと安心）
- 通知は、**そのiPhoneで選んでいるプロフィール**が担当する応募アカウントについてだけ届きます。AのiPhoneに、Bの未応募の通知は届きません。
- **プロフィールを切り替えると、この端末の通知先も自動で切り替わります**（1台のiPhoneは常に1つのプロフィールに紐づきます）。切り替えを忘れたまま使うと、前のプロフィール宛の通知が止まる点にご注意ください。
- 次の場合は**通知されません**: 応募済み／スルー（今回・店舗・系列）／応募対象外／1家族1回などで枠が埋まっている／資格や制限が未確認（要確認）／★管理対象外（応募漏れ通知）。
- 締切の**時刻が不明（日付のみ）**のときは、時刻を仮定せず、**当日の朝に「時刻未確認」として**通知します（設定で通知しないことも可能）。
- 通知が使えない・見逃したときのために、抽選管理ページの上部に **「要対応」** が表示されます。
- OS や通信状況により、通知は**数分遅れる**ことがあります。締切の管理は画面でも必ず確認できます。

## うまくいかないとき
| 症状 | 確認すること |
|---|---|
| 「通知を有効にする」が押せない／表示されない | ホーム画面のアイコンから開いているか（Safariのタブでは不可）。iOS が 16.4 以降か |
| 許可ダイアログが出ない／拒否してしまった | iPhone の **設定 → 通知 → 「トレカ抽選」** で通知を許可。表示されない場合は、ホーム画面のアイコンを長押し →「Appを削除」→ 手順2からやり直す |
| テスト通知は届くが、本番の通知が来ない | 設定 →「通知」の **通知ジョブ（サーバー）** が「有効」で、最終成功が数分以内か。「定期実行: 未設定」の場合はまだ自動配信が始まっていません |
| 通知が来ない（時々） | 集中モード／おやすみモードの設定、低電力モード、通知の「時間指定の通知」を確認 |
| 別のプロフィールの通知が来ない | その端末で選んでいるプロフィールが担当者か（上部の丸いアイコン）。「状態」に表示される通知先を確認 |
| 通知を止めたい | 設定 →「この端末の通知を停止」。または iPhone の設定 → 通知 → 「トレカ抽選」 |

## 動作確認チェックリスト（導入時に1回）
- [ ] ホーム画面のアイコンから開ける
- [ ] 通知を有効にし、テスト通知が届いた（夫・妻それぞれのiPhone）
- [ ] 端末でプロフィールを切り替えると、「通知先」が切り替わる（戻すと戻る）
- [ ] 応募済みにした抽選の締切前に、その担当者には通知が来ない
- [ ] （通知ジョブ有効化後）締切2時間前に近い未応募の抽選で、実際に通知が届く
