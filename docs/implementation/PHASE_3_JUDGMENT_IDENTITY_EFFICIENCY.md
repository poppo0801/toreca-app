## 4. 1候補あたり費用の最適化（性能を保つことを前提）
- 前回の平均約16円（195.26/12、以前約2.5円とは同条件でない）。主因とされるSonnet追加調査を、案件ごとの一次→上位の根拠変化・判断変化・改善/悪化・無変化・費用・遅延・失敗で分析。既存のログを優先。単純案件をHaiku medium＋思考で完結、難しい場合のHaiku high、Sonnet medium/high・追加調査、既存証拠/過去の人の訂正/判断経験の再利用などをAIが必要性に応じ選択できる構成を試す。固定案件分類・一律昇格/抑制・思考停止はしない。全件独立監査を必須にしない。AIが必要な道具を使えることを前提に費用対効果を比較。性能が改善しない高額な呼び出しを削減し、安価な検索・保存証拠・キャッシュ・同一機会間の共有で重複作業を減らす。不要文字削減は今回対象外。
- まず十分な性能の基準構成を確立してから、同じ実案件・証拠・正解・基準時刻で、判断精度/重複/網羅性を維持できる1候補予算と実費の関係を段階的に評価（例えば現行25円枠と、それより十分な枠、合理的に低い枠。数値はログと必要費用から選び、新たな恒久制約としない）。既存結果の無課金分析、少数の代表案件で絞り込み、最有望構成を独立未見で確認。性能不足のまま費用だけ下げない。必要なら追加予算承認を即取得。平均/中央値/p90または高額案件・全費用（失敗/再開/検索/画像含む）・正しく完結した候補/機会1件あたり費用、日次処理能力、実運用の到着数/滞留/締切遅延を示す。安いが未完了のものは安価な成功扱いしない。上限値と実費を区別。予算最適案を提案し、承認なしで本番上限を下げたり引き上げたりしない。
## 5. 目標・評価・実用化の判断

- 新旧・前回構成・改善後を実データで比較。現在の正解率だけでなく誤りの重さ、登録案の実用性、人が確認/修正する負担を評価。独立した正解、候補単位/機会単位、判定/取得/同一性を区別。重要項目・全項目の分母に漏れ機会が含まれるか点検し、既知の重複を正解にせず、同じ案件を複数回合算して未見の成績としない。既存診断セットを活用し、新しい独立未見は代表性を考慮。目標に向けた改善の実証を優先、目標達成を装うための固定ルールや大量試験は不要。
