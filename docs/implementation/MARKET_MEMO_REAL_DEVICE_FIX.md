# 相場調査メモ 本番実機不合格の是正指示

## 不合格の根拠と再発原因
ユーザーの2026-11-22本番実機スクリーンショットでは相場調査メモの一覧にポケモン画像が無く、店舗名が「トレカキャピタル…」で切れ、右上に不要なJSONダウンロードボタンが残る。監査表 `docs/reports/2026-11-22-ui-requirements-audit.md` はD1/D3/D4を適合としたが**実機の要望充足とは一致しない**。監査表の「不透明度に関するテスト」だけでは画像が実際に表示されることを検証できない。また価格記録のコンパクト表示と、相場調査メモのカード一覧の情報設計を混同しない。

現行 `src/components/market-memo-view.tsx` に `exportJson` と `market-export` ボタンが残り、`CardRow` の画像は `dexOfCardName` による151限定推定。全ポケモン画像をStorageに保存しているのに151以外を引けない。まず現行mainのコードと本番データの構造を再確認する。

## 修正範囲
1. **相場メモのカード一覧に画像を表示**。151匹以外も含む既存private Storageの画像に対応。現行カード名（例:「ミロカロス」「デデンネ」「バチュル」「ブルンゲルex」「ピィ」「ドリュウズex」「コドラ」「メテノ」「メレシー」「オドリドリex」）について実データで番号/形態/画像を正しく特定できるか検証。単純な名前一致で誤画像を出さない。カード名とポケモン名を分離する必要があれば、既存カードデータを壊さない後方互換の解決方法を設計。全ポケモン用の番号→画像キー対応を確認し、未対応や曖昧な場合は安全なプレースホルダー。画像の不透明度100%、少し小さめ、既存private API・世帯認証を維持。非公開画像を公開リポジトリへ入れない。
2. **一覧の情報設計を再検討**。カード名・セット/番号/レア・比較に必要な価格/店舗/状態/件数を、390px幅で読みやすく。長い店舗名が不自然に切れて意味を失わないよう、必要なら店名の表示場所・行数・省略規則を調整。現行の「最安価格＋店名が途中切れ」は不合格。**ユーザーの過去の確定した並び順/表示要望をリポジトリ内の指示書・設計md・履歴から照合**して厳守する。具体的な順序が確定していない場合は勝手に確定せず、実装案を明示して確認を求める。カード一覧とカード詳細の価格記録一覧を別々に検証。
3. **不要な右上のJSONダウンロードボタンを削除**。他画面で既存のバックアップ/エクスポート機能が必要なら残し、相場メモのヘッダーからだけ外す。検索と右上の「＋」は維持。不要な説明を増やさない。
4. 151図鑑・購入記録・価格フォームの既に適合した仕様は回帰させない。価格登録の状態A/レアAR初期値、系列/店舗必須と過去候補、価格一覧タップ後詳細などを維持。
5. **監査を修正**。旧監査表D1/D3/D4を実機不合格と明記し、各項目について本番データを用いた画像表示・UIの検証証拠（スクリーンショット、画像HTTPレスポンス、表示された画像番号、店名の視認性）を残す。「opacity無し」を「画像が表示された」と同一視しない。未確認なら「未確認」とする。
6. 画像読み込み速度は既存の非公開APIの測定を活用し、失敗リクエスト・未マッピング・ネットワーク遅延を区別。画像の大量一括変換はこのUI是正に混ぜない。既存画像配信に影響する変更は必要最小限。
7. UI専用ブランチで実装、型/lint/build/単体/E2E、390px幅の相場メモ一覧（画像有/画像無/長い店名）、カード詳細、151図鑑の回帰テスト。CI→PR→マージ→本番デプロイまで（承認済みのUI修正範囲）。本番のログイン後画面をClaude Codeが確認できないなら**完了と断定しない**でユーザーへ検証ポイントを示す。AI情報収集コード、DBマイグレーション、本番画像公開設定は変更しない。
