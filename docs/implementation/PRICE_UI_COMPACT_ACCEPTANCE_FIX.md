# 相場価格UIの仕様逸脱是正（本番反映まで）

## 背景と原因
本番UIの実機スクリーンショットで、価格一覧に購入/編集/削除ボタン・「この店の推移」が常時表示され、1件が縦長。登録フォームも希望順でない。旧指示書 `docs/implementation/UI_COLLECTION_POLISH_PRODUCTION.md` は「省スペース化」「入力しやすい順序」と抽象的で、受入条件を欠いた。現行 `src/components/price-list.tsx` は一覧内にボタン・履歴を直接描画、`src/components/price-form.tsx` は希望と異なる順序。**これは未実装の仕様漏れ**。今回の確定要望を優先する。

## 価格一覧（151図鑑・相場調査メモ共通）
- 各価格は**高さを抑えた1行相当のタップ可能なブロック**。情報順は**状態ランク → 系列・店舗 → 調査日 → 金額**、**金額を右端**に揃えて比較しやすく。スマホ幅では店舗名と日付を中央に2行まで使ってよいが全体はコンパクト。横幅に応じて省略、価格は桁を揃え折り返さない。
- 一覧の**常時表示は上記4情報のみ**（最安/購入済み/参考価格の区別が必要なら控えめな色や記号で示す。大きな説明ラベルを増やさない）。「この価格で購入」「編集」「削除」「この店の推移」リンク、備考、説明は一覧に**絶対に常時表示しない**。
- **価格ブロックをタップ**するとその記録の詳細（シート/展開領域）を開く。詳細に備考、最安・参考価格・購入済み情報、同じ店舗の価格推移、購入・編集・削除を配置。編集/削除は既存確認フローを維持し、誤操作を防ぐ。閉じる操作、キーボード/アクセシビリティ対応。並び替え（状態優先/価格安い順）、30日超の参考価格、履歴、購入済みの二重購入防止は維持。
- `PriceList` は両画面共通なので、151図鑑詳細と相場調査メモの両方で同じ挙動を確認する。

## 価格登録フォーム（151図鑑・相場調査メモ共通）
- 必須項目を上にまとめ、順序は**カード名 → 系列 → 店舗 → 調査日 → 販売価格 → 状態ランク**。カード名が図鑑詳細で確定済みの場合は読み取り専用または省略可、相場調査メモではカード名を最上部に表示。**系列→店舗の順**を守る。
- **系列・店舗はどちらも必須**。履歴やマスターから系列・店舗・収録セット・カード番号・レアリティの候補を出す。過去の系列＋店舗を**ワンタップで両方反映**する候補ボタンを提供。候補がない場合は手入力可能。自動フォーカス・自動プルダウン起動は禁止。
- 調査日は今日を初期値、**状態ランクAを初期選択**。価格は必須。**任意項目（収録セット/番号/レア/備考等）は必須項目の下**にまとめる。ただしカード同定の既存必須条件がある場合はデータ整合性を優先し、フォームの表示順とDBの要件を切り分ける。
- 同一系列・店舗・調査日の**状態違い価格を複数まとめて登録**できる機能は維持。状態の重複や不正入力は保存前に検証。途中失敗時に何件保存済みか明示し、二重登録を避ける。
- 入力欄の縦余白を抑え、スマホで主要必須項目がなるべく少ないスクロールで見えるようにする。既存の編集画面でも整合性を保つ。

## 151図鑑詳細の説明整理
- 「対象レア未収録」チェックの**下にある説明文をすべて削除**。チェックと短い項目名だけを残す。手動ON/OFFの挙動と入手済み・相場登録済みの優先順位は維持。
- ポケモン名の下の「状態: 相場登録済み（価格調査の記録あり）」等の文章は**削除**。状態表示が必要なら**短い色分けバッジ1個**で示す（例:「相場登録済み」）。説明括弧は不要。
- **151図鑑の一覧カードには状態の文字バッジを追加しない**。今回のバッジ許可は**詳細ヘッダーのみ**。既存の背景色区分を維持。
- 画面全体の長い補足・使い方説明・冗長な文言を整理。誤操作を防ぐために不可欠な確認文やエラーは維持。
