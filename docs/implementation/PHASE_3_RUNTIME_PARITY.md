- SSRF/リダイレクト各段の検査、公開情報限定、秘密・個人情報の送信禁止、外部文書の命令無視、利用規約・アクセス頻度・サイズ・時間・回数上限を既存実装で担保。ログにキーや不要な原文を残さない。ログインや認証回避は行わない。地域条件は既存設定から正規取得し、機会の実在と利用者への適合を別軸にする。
