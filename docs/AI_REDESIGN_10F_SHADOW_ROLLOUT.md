状態: **ローカルの無課金シャドー基盤まで実装済み（`src/lib/judgment/shadow/`）。以降の段階はすべて未承認・未実装。** 旧方式が唯一の正式な判断・登録経路で、新AI方式は比較用の判断を記録するだけ。

## 1. シャドーの原則（実装済みの性質）
| 性質 | 実装 |
|---|---|
| 初期OFF | `SHADOW_JUDGMENT=on` かつ `TOREMANE_ENV=local`・`NODE_ENV≠production`・`VERCEL*` なし、のときだけ有効（`config.ts`） |
| 本番・実AIの拒否 | 実AIモード（`SHADOW_JUDGMENT_MODE=real`）は常に無効（未承認）。ネットワーク・Anthropic・DBのモジュールを読み込まない（静的検査のテスト） |
| 正式経路に作用しない | 判断履歴の sink を渡さない＝DBに書かない。カード・応募/当選/購入履歴・通知・保護対象に触れない。旧方式の要約は値のコピーで受け取る |
| 失敗しても旧方式は継続 | `observe()` は例外を投げない。モデル例外・不正出力・ハング（打ち切り）・保存失敗のいずれでも結果を返して終わる |
| 上限 | 時間窓あたり件数・同時実行数・1件のタイムアウト・シャドー全体の費用上限と1件の上限（事前予約）。既定は 20件/時・同時1・20秒・5円・2円 |
| 重複実行防止 | 入力＋プロンプト版のハッシュで、実行済み・実行中を拒否 |
| 緊急停止 | `SHADOW_JUDGMENT_KILL=1`（または `SHADOW_JUDGMENT=off`）で、**環境変数を読み直す**ため再起動なしで次の呼び出しから停止。旧方式への即時切戻しは「シャドーを呼ばない」だけ（旧方式は常に動いている） |
| 記録は非機微 | 列挙値・数値・短いハッシュ・ISO日時のみ（`assertSafeRecord`で保存前に検査）。原文・URL・既存の抽選ID・店舗/商品名・認証情報は含まない。保存先は `eval/runs/shadow/`（Git管理外） |
| 比較は「疑い」 | 構造・機会数・関係・保留・根拠つき主張の割合・誤統合の疑い・誤分割の疑い・費用・遅延を記録。**旧方式が表現できない構造（商品別・開催回別・1送信複数独立）は不正解にしない**。goldなしでは精度を断定しない（集計に注意書き） |
