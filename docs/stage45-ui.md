## 名称・ロゴ
- 表示名は **トレマネ**（副題 TCG manager）。内部のプロジェクト名・GitHubリポジトリ名・Supabaseプロジェクト名・Vercel URL は変更していない。
- ロゴは「トレマネ アプリアイコン提案ボード」（`docs/references/`）の **案1**（重なった3枚のカード＋オレンジの星）。ボードの画像は低解像度の合成画像なので、案1の構図をSVGで再現した（`src/lib/brand-svg.ts`）。元の高解像度データがある場合は `public/icons/` のPNGを差し替えれば反映される。
- 反映先: アプリヘッダー、PC左ナビ、ログイン画面、ページタイトル、PWAの表示名（manifest）、ホーム画面アイコン（apple-touch-icon / 192 / 512 / maskable）、favicon、通知のタイトル（Service Worker）、ローカルバックアップの通知。
- アイコンの再生成: `node scripts/generate-icons.mjs`

## デザイン
- ダーク: 背景(黒) < ヘッダー < カード < 入力欄 < ボタン面 の順に明度差を大きく、細い枠線を併用。カード・ボトムシートに控えめな影。オレンジは主要操作・選択状態・ヘッダー上端のライン・締切の強調に限定し、状態表示には青緑・緑・赤・黄を使う。
- ヘッダーは「ロゴ・名称・通知ベル・現在のプロフィール1つ」で高さ約43px。下部ナビは4項目（抽選管理・購入記録・収支・設定）で操作行3.25rem。Safe Area（上下左右）対応。

## 抽選一覧
- カード: 左に大きな商品画像（縦横比維持。透明な余白は表示時に詰める＝`product_images.content_box`。元画像は変更しない）、正式商品名、系列・店舗、応募締切（残り時間バッジ）、発表日、受取方法。不明は「—」。複数商品は代表＋「＋他N商品」。右上に都道府県ラベルと自宅からの直線距離（Stage 5B）。
- ユーザー状態は小さなアイコン＋色。「？」だけの表示はやめ、要確認は注意アイコン。意味は一覧上部の「?」ボタン（凡例）で確認できる。
- **カードをタップすると詳細（下から開くボトムシート）**。重要な順に 商品→日時（2カラム）→方法→URL→条件・制限→ユーザー別（折りたたみ）→備考・操作。閉じると一覧のスクロール位置に戻る。
- 見出し・タブを固定し、その下だけスクロール。検索はコンパクト、詳細フィルターは初期非表示（フィルターボタン、適用数をバッジ表示）。タブ・フィルターはこのタブを閉じるまで保持。★管理対象は自分がスルーしたものを初期除外（含む／のみは維持）。
- 応募状況マトリクス（状態一覧）: 列は**ユーザー**（A/B/C）に集約し、iPhone幅で横スクロールなしに同時表示。状態はアイコン、系列・店舗は2行（店舗は小さな補助文字、タップで全文）。

## 登録・編集フォーム
- 下から開くパネル。系列・店舗 → 商品・数量 → 日時（2カラム）→ 方法 → URL → 条件・制限 → 詳細設定（抽選方式・キャンペーン・状態・本人確認・メモ）の順で、縦の長さを約1/2に圧縮。複数商品の方式（A〜D）は詳細設定。
- **日時**: 「不明/日付のみ/日時」の事前選択は廃止。空欄＝不明、日付だけ＝日付のみ、日付＋時刻＝日時。**時刻未設定と0:00は区別**し、23:59などを補わない。既存データの精度情報はそのまま。時刻だけ入力して日付が空の場合は保存できない。
- **初期値**: 応募方法・受取方法に初期値（同系列の直近の確かな設定、なければ Web／店頭）。点線の枠と「初期値」の印で、利用者が選んだ値・AIが読み取った値（「AI」の印）と区別。初期値のまま保存した項目は `lotteries.unconfirmed_fields` に記録し、詳細に「初期値・未確認」と表示。選び直すと外れる。応募制限には初期値を置かない（判定に直結するため）。
- **下書き**: 入力は端末内（localStorage）に自動保存（14日保持）。最小化（一覧を見ながら再開できる）、閉じても残す／破棄の選択、「下書き」ボタンで再開、リセット、登録完了で削除。認証情報などは保存しない。
- **保存競合**: 編集を始めた時点の更新日時を、保存の直前に最新と比較。他の端末で更新されていれば警告し、「最新の内容で入力し直す」「このまま上書き保存」を選べる。
