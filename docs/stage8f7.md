## 2. 分析（原因の分類）
- **AIの過剰保留**: 条件はすべて一致し、形態（店舗選択式か店舗別独立か）だけが未確認のとき、AIが自分で hold にしていた。検証層は本来この場合を「候補（suggest）」にする設計。→ 指示文を修正（形態だけ未確認なら new_group を提案し、検証層が候補にする。店舗選択欄などの構造の根拠があるときだけ single）。
- **基盤の不具合（評価側ではなく本体）**: 再調査の依頼のあと、AIが再提出せず説明だけで終了すると、直前の有効な提出が空の出力（保留）で上書きされていた（`core.ts`）。→ 再提出が無いときは直前の有効な提出を保持する。
- **検証層の穴**: 形態が未確認でも、他がそろい別の裏づけがあれば、AIの提案で auto になりえた。実データの店舗選択式（M01・M03・M05 など）に共通するのは「複数店舗が同じ1つの応募ページを共有し、店舗ごとの受付の構造が無い」点。→ **同じ応募ページを共有していて、店舗ごとの独立した受付を構造で確認できないものは auto にしない（候補止まり）**。店舗ごとにページが別・構造の記載・手動の確認があれば従来どおり auto。個別のケース・店舗・系列を条件にしていない。
- **正解データの扱い**: 8f3 の M01〜M06 などの正解 review は、8F-5 の定義に基づく（店舗選択式の記載があり利用者の確認が必要）。8F-6 の形態の定義では、店舗選択式はグループ化ではなく整理候補が本来の扱いで、候補化（suggest）が正解の review と合致するかは解釈の余地がある。凍結済みの正解は変更していない。
- **残る過剰な保守性**: H06（応募条件が一方だけに記載。購入履歴が必要）は正解 none だが、AIも検証層も hold（確認が必要）。「異なる」と「記載なし」を区別する 8F-3 の方針と、正解ラベルの間に緊張がある。誤ってまとめてはいないため安全側。正解の見直しは新しいデータ組で行う（既存の凍結は変えない）。

## 3. 実装した改善（一般化できるもの）
- `verify.ts`: 同一の応募ページを共有・形態が構造で確認できない → auto にしない。
- `run.ts`: 指示文（形態だけ未確認なら提案する）。
- `core.ts`: 再調査後に再提出が無い場合は直前の有効な提出を保持。
- `form-cleanup.ts`: 手動で店舗別独立・その他にした組は候補から外す。手動の店舗選択式でも、単独のカード（二重登録ではない）は候補にしない。
- 単体テスト追加（共有ページ＋構造不明→suggest、構造・手動・別ページ→auto、再提出なしの保持）。8F の既存DBテストのデータに店舗別受付の記載を追加（新しい上限の意図した変更）。

## 4. 店舗選択式の整理候補UI（開発環境のみ。`/settings/lottery-grouping` の先頭）
- 目的: 本来1件の店舗選択式の抽選が、店舗ごとの別カードで登録されている疑いを、利用者が安全に整理する。同じ系列・商品というだけでは候補にしない（店舗選択欄などの構造、または店舗選択式のカードと同じ情報源URL）。
- 表示: 系列名、判定の根拠（折りたたみ）、カード一覧（店舗・商品・締切・「残すカード」「応募の記録あり・退避しない」「手動の分類」）。
- 操作:
  - 「整理する」: 店舗選択式のカードが既にあるときだけ。2回目のクリックで実行。**応募の記録が無いカードだけ**を退避（`archived_at`。物理削除なし）。実行直前にも応募の記録を再確認。
  - 「別の抽選として残す」: 手動の分類（店舗別独立）を記録。候補から外れ、以後AI・収集は上書きしない。
  - 「店舗選択式として扱う」: 店舗選択式のカードが無い組で、手動の分類（店舗選択式）を記録（整理（退避）は、先に1つのカードを店舗選択式にしてから）。
  - 復旧: 「元に戻す」（退避を取り消し。30日以内）、「分類を解除」（手動の分類を外して構造からの判別に戻る）。
- 安全: 操作の対象は、実行時に再計算した候補のキーと一致するものだけ。応募・当選・購入・通知の履歴は変更しない。本番ではDBに触れる前に拒否（`isLotteryGroupingEnabled`）。
- 実装: `src/lib/server/agent/select-cleanup-service.ts`、`cleanup-actions.ts`、`src/components/select-cleanup-panel.tsx`。`restoreLottery` を追加。
- テスト: DB結合2件（整理・保護・復元・手動の記録と解除）、E2E（iPhone幅 390px。横はみ出しなし。画面を確認）。
