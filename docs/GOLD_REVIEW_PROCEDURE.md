# 独立 gold（正解）を増やすレビュー手順

作成日: 2026-11-23 ／ 目的: 新AIの判断精度を測るための「独立した正解」を、人が根拠つきで確定する。**AIの出力・旧アプリの出力・検証の通過は正解にしない。**

## 定義
- **gold**: 人が「正しい応募方式（応募単位）」を**明示**し、かつ**確認した根拠の記録（メモ6文字以上）**がある事例だけ（`scripts/lib/gold-c.mjs`）。
- gold にしないもの: 「以前のAIへの『正しい』評価のみ」・判断不能・未回答・応募ページ未取得で根拠が確認できないもの・**根拠メモが無いもの**。
- 現状（2026-11-23）: gold 3件／根拠メモなし 6件。**正答率は gold が10件に達するまで出さない**。

## 手順（利用者の作業。AIは回答を書かない）
1. `node scripts/gold-worksheet-10z.mjs` … 根拠メモなしの事例を、原文・人が指定した応募方式つきでローカルのワークシート（`eval/real-data/gold-worksheet-10z.md`・Git管理外）に出す（読み取り専用）。
2. 事例ごとに、**元の原文・応募ページ・出典**を自分の目で確認する（AIの判断・登録案は見ない／参考にしない）。
3. `node scripts/review-10s-local.mjs` で確認画面（自分のPC内だけで動く）を開き、「誤り（正しい方式を指定）」または「正しい」を選び、**メモに根拠**（どのページのどの記載で確認したか）を6文字以上で書く。回答は追記方式（過去の回答は書き換わらない）。
4. `node scripts/gold-worksheet-10z.mjs` を再実行して、gold の件数を確認する。10件に達したら精度を測れる。
- 根拠の書き方の例（形式の説明。実データではない）: 「応募ページの『受付枠』が店舗ごとに独立（ページ内の見出し）」「公式告知の『店舗選択式』の記載を確認」。
- 追加の事例が必要なとき: 実AIの試験（`scripts/proposal-real.mjs`）の結果のうち、**人が自分で確認した事例**を、同じ手順で回答に追加する（AIの結果を見る前に原文を確認する）。

## 注意
- 回答・原文・URL・gold は Git に入れない（`eval/real-data/` はGit管理外）。
- 人が確定した値・レビューは、AIが上書きしない（登録案のレビューは追記専用）。
