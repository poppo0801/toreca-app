## 3. 実装した改善（マイグレーションなし）
1. **日時の意味比較**（`collector/date-phrases.ts`・`fields.ts`）: 11:59と12:00、23:59と翌0:00（差2分以内）は同じ締切の表記差とし、早い方を採用。同じ日の日付のみと時刻つきは詳しさの違い（時刻つきを採用）。1日以上・数時間の差は矛盾のまま。
2. **主催者本文の優先**（`FieldSource.basis`）: 日時が食い違うとき、主催者の説明本文（`organizer_body`）をサービス側の表示（`platform_meta`）より優先。手動確定の値は上書きしない。※取得側が `basis` を付ける接続は今後（現状は仕組みのみ）。
3. **AI指示文**（`ai/provider.ts`、PROMPT_VERSION `2026-11-14.1`）: X本文と画像は補完関係（画像にない商品を除外しない）、LivePocket本文優先と境界表現、当選発表の表現（期間・終わりだけ・目途）。
4. **当選発表日の補完**（`collector/date-supplement.ts`）: AIが読み取れなかったときだけ、本文の表現（期間／「○日までに連絡」／目途・予定）から補い、確定日でないことを警告に記録。AIの値は上書きしない。「販売開始日までに」（日付なし）は無理に補わない。※開始日が不明で終わりだけの場合は、現在の入力形式の制約上、終了日を発表日として記録し警告で明示（終了のみの項目は将来の課題）。
5. **店舗選択式の構造判定**: フォームのプルダウン・ドロップダウン・選択欄・ラジオボタンで店舗を選ぶ記載を店舗選択式の根拠に追加（`store-select.ts`・`lottery-form.ts`）。
